Set up this phone

Trust this computer's certificate once, and the demo opens over HTTPS: it can then be installed as an app and works offline.

Download the certificate

iPhone and iPad

  1. Open this page in Safari and tap Download the certificate, then Allow.
  2. Open Settings and tap Profile Downloaded near the top, then Install.
  3. Go to Settings › General › About › Certificate Trust Settings and turn on FlopGPT Local CA.

Android

  1. Tap Download the certificate.
  2. Open Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate (search Settings for “CA certificate” if it's elsewhere), and pick FlopGPT-CA.crt.
Open the demo over HTTPS

The installed app is tied to this address. If the computer's address or port changes, open the new one and install it again.
